ADMIN TV PANEL
================
Reference-style compact IPTV administration panel.

Brand:
- ADMIN logo is included at assets/admin-logo.png (user supplied).
- Header identity is ADMIN / Administrator.

Working features:
- Dashboard statistics and refresh
- Channel Manager search/filter/pagination
- Add / edit / delete / preview channels
- M3U/M3U8 text import and file import
- Category add/remove
- Website settings and notice/banner persistence
- JSON backup/restore
- M3U export
- Clear/reset tools
- Live preview, play/reload/fullscreen/open
- Theme toggle
- Mobile compact layout without permanent left sidebar

Data is stored in browser localStorage in this demo. Replace app.js storage calls with your Worker/API endpoints when connecting to a production backend.
